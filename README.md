# AI-Powered Smart Exam Proctoring System

## 📌 Project Overview
An intelligent AI-based online examination monitoring system 
developed to detect suspicious activities during online exams 
using real-time webcam and audio analysis.

## 🛠️ Technologies Used
- Python
- Django
- OpenCV
- MediaPipe
- Whisper AI
- HTML, CSS, JavaScript
- SQLite

## 👥 User Roles
- **Admin** - Monitors exams and manages users
- **Student** - Attends online examinations
- **System AI** - Detects suspicious activities automatically

## 🔒 Key Features
- Real-time face detection
- Audio activity monitoring
- Head movement tracking
- Suspicious activity alerts
- Secure login authentication
- Online exam monitoring dashboard

## ⚙️ How to Run
1. Install Python and required dependencies
2. Clone the repository
3. Create and activate virtual environment
4. Install requirements using `pip install -r requirements.txt`
5. Run migrations using `python manage.py migrate`
6. Start server using `python manage.py runserver`
